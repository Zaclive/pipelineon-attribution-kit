CONVERSION FEEDBACK
Send outcomes to Meta
Connect your destination
Set KIT_META_DATASET_ID and KIT_META_ACCESS_TOKEN on your server. Start with KIT_META_MODE=test and the KIT_META_TEST_EVENT_CODE from Events Manager. Restart after changes. Add the versioned Meta fields to your outcome feed; the README has the complete example. The dashboard stays read-only.


Send outcomes to Google Ads
Validation, submission and processing are separate. Google processing does not establish an ad match or attributed sale. Configure the server using the Google Ads guide in this bundle.


WEBSITE CALLS
CallRail connection
Setup and recovery
Follow CALLRAIL.md to set your API key, company signing key, webhooks and consent-aware cookie bridge. This dashboard is read-only. Recover a missing call by POSTing its callId to /v1/callrail/retry with a server-side write token. A call receipt is separate from a Meta delivery receipt.
